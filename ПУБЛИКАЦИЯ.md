# Лабораторная работа 5: GitHub, GitLab, Bitbucket

Локально уже сделано: три копии репозитория, ветка `new-branch` и по 3 коммита в каждой.
Остаётся создать аккаунты/репозитории на сайтах и отправить код.

В каждой папке замените заглушку `<ваш_логин>` на реальную ссылку и выполните push.

## GitHub
```
cd github-repo
git remote set-url origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПО.git
git push -u origin master
git push origin new-branch
```

## GitLab
```
cd gitlab-repo
git remote set-url origin https://gitlab.com/ВАШ_ЛОГИН/ИМЯ_ПРОЕКТА.git
git push -u origin master
git push origin new-branch
```

## Bitbucket
```
cd bitbucket-repo
git remote set-url origin https://bitbucket.org/ВАШ_ЛОГИН/ИМЯ_РЕПО.git
git push -u origin master
git push origin new-branch
```

Проверка истории: `git log --oneline --all --graph`
